# Laptop Data Cleaning and Exploratory Data Analysis

## 📌 Project Overview

This project focuses on cleaning and exploring a real-world laptop dataset using Python.
The dataset contains multiple unclean attributes such as RAM, CPU, GPU, memory, and weight, which are processed to make the data analysis-ready.

## 🛠️ Tools & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Key Features

* Removed unnecessary columns
* Cleaned and transformed categorical and numerical data
* Converted data types for analysis
* Performed exploratory data analysis (EDA)
* Visualized insights using graphs

## 📁 File Structure

* `laptopsnshw.ipynb` – Main notebook containing data cleaning and EDA

## 🎯 Learning Outcomes

* Practical experience with real-world unclean data
* Strong understanding of data preprocessing
* Hands-on practice with visualization libraries
